# CLAUDE.md

Regras e memórias para o Claude Code neste projeto.

## Regras

1. **Comentários mínimos**: no máximo 2 linhas de comentário por trecho de código. Seja direto e conciso, sem explicações desnecessárias.
2. **Deploy no Cloudflare Workers**: nunca fazer deploy sem autorização explícita do usuário. Antes de perguntar, informar claramente qual Worker será alvo do deploy.
3. **Idioma**: use a linguagem PT-BR para responder, comentar e entre outras interações neste projeto.
